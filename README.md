# Weather Data Analysis with Python

## Tools & Technologies

- Python
- Pandas
- Google Colab

## Analysis Questions

1. Find all unique values of wind speed.
2. Count the occurrences of weather conditions that are exactly `Clear`.
3. Count the occurrences where wind speed is exactly 4 km/h.
4. Identify missing values in the dataset.
5. Rename the `Weather` column to `Weather Condition`.
6. Calculate the mean visibility.
7. Calculate the standard deviation of pressure.
8. Calculate the variance of relative humidity.
9. Find all records where `Snow` was recorded.
10. Find all records where wind speed is above 24 km/h and visibility is 25 km.
11. Calculate the mean of each numerical column grouped by weather condition.
12. Find the minimum and maximum values of each numerical column grouped by weather condition.
13. Display all records where the weather condition is `Fog`.
14. Find all records where the weather condition is `Clear` or visibility is above 40 km.
15. Find all records where the weather condition is `Clear` and relative humidity is greater than 50%, or visibility is above 40 km.

## Commands Used

- `head()` – Displays the first five rows of the dataset by default.
- `shape` – Returns the number of rows and columns.
- `index` – Displays the DataFrame index.
- `columns` – Displays the column names.
- `dtypes` – Shows the data type of each column.
- `unique()` – Returns all unique values in a column.
- `nunique()` – Counts the unique values in a column or across DataFrame columns.
- `count()` – Counts non-null values.
- `value_counts()` – Counts the occurrences of each unique value in a column.
- `info()` – Provides basic information about the DataFrame.
- `isnull()` – Identifies missing values.
- `rename()` – Renames columns.
- `mean()` – Calculates the average.
- `std()` – Calculates the standard deviation.
- Boolean filtering – Selects rows that meet specific conditions.
- `groupby()` – Groups data by weather condition for statistical analysis.
- `min()` and `max()` – Find minimum and maximum values.

## Learning Outcomes

Through this project, I practiced using Python and Pandas to inspect datasets, identify missing values, filter records, calculate descriptive statistics, and group data by weather conditions.
